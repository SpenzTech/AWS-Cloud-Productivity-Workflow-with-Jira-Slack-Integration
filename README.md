# AWS-Cloud-Productivity-Workflow-with-Jira-Slack-Integration
This project demonstrates the implementation of a cloud-based project management workflow using Atlassian Jira Cloud integrated with Slack for real-time team collaboration and automated notifications. The objective was to simulate how modern cloud and DevOps teams manage software projects by planning, tracking, monitoring, and communicating throughout the software development lifecycle.

This project was completed as part of the Azubi Africa AWS Cloud Computing & AI Program.

🎯 Objectives
* Create a cloud-based project management workflow
* Organize project tasks using Jira Kanban Boards
* Prioritize and manage project backlog
* Track issue progress through different workflow stages
* Configure Slack integration for automated notifications
* Monitor project performance using Jira dashboards
* Simulate collaboration within a cloud engineering team

🔄 Workflow Statuses
The Jira workflow consists of:
* To Do
* In Progress
* Review
* Testing
* Done
Each issue moves through these stages until project completion.


💬 Slack Integration
Slack was integrated with Jira to automate project communication.
Notifications include:
* New issue created
* Issue assigned
* Status changed
* Task completed
* Sprint updates
* Workflow progress
This enables real-time collaboration without constantly checking Jira.
